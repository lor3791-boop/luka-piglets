# luka-piglets

루카 후기자돈사 전입출 현황판 — 주차별 전입·전출 물량과 재고를 관리하고, 캘린더로 농장과 공유하기 위한 웹사이트.

- `index.html` — 웹사이트 전체 소스 (Claude Artifact로 배포되어 실제로는 아래 링크에서 서비스됩니다)
- `입력양식.xlsx` — 전입·전출 내역을 정리해서 웹사이트에 그대로 불러올 수 있는 엑셀 양식
- `build_template.py` — 위 엑셀 양식을 생성하는 스크립트 (openpyxl 필요)

실제 서비스 링크: https://claude.ai/code/artifact/0534fbb2-098f-4b8a-a5a4-480a01d8fa40

이 저장소는 소스 백업/버전관리용이며, `index.html`을 고친다고 위 링크가 자동으로 갱신되지는 않습니다.
